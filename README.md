# Atelier Gris Perfumería

Página de la tienda. Se publica sola con GitHub Pages cada vez que se guarda un cambio.

## Qué hay en cada archivo

- **perfumes.js**: el catálogo (perfumes, precios, textos y notas) y las tarifas de envío. Es el archivo que normalmente vas a editar.
- **index.html**: el diseño de la página. Mejor no tocarlo sin ayuda.
- **fotos/**: las fotos de los frascos.

## Cómo cambiar un precio

1. Abre `perfumes.js` y presiona el ícono del lápiz (Edit).
2. Busca el perfume y cambia el número en `precio: 2999`. Sin signo $ ni comas.
3. Presiona **Commit changes**. En uno o dos minutos la página muestra el cambio.

## Reglas para no romper nada

- Conserva las comillas `""` alrededor de los textos.
- Conserva la coma al final de cada línea y entre perfumes.
- Si algo deja de verse, se puede regresar a la versión anterior desde el historial (History).
